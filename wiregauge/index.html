詳しく

その回路に、何 AWG の銅線を使えばいいのか。WireGauge は、電流・片道の配線長・システム電圧の3つから、安全に使える最小の電線サイズを数秒で出します。ボート、キャンピングカー、バン、車、ソーラーの 12V / 24V / 48V の DC 配線のためのアプリです。

二つの基準を同時に見る

世の中の早見表は、電圧降下か許容電流のどちらか片方しか見ていないものがほとんどです。けれど実際には、長い配線では電圧降下が、短くて大電流の配線では許容電流が太さを決めます。WireGauge は両方を計算し、今回どちらで決まったのかまで表示します。

計算するもの

  • 安全に使える最小の AWG。
  • その太さでの実際の電圧降下（V と %）。許容値を超えていれば赤で出ます。
  • その太さの許容電流（耐熱温度と束ねる本数で低減した値）。
  • 電圧降下と許容電流の、どちらが効いているのか。
  • 4/0 でも足りない場合は、その旨と対処（負荷を分ける、電圧を上げる、短くする）。

数字の出どころ

  • 電圧降下は ABYC の往復モデル（2 × 片道長 × 抵抗 × 電流）で計算します。
  • 許容電流は ABYC E-11 Table 6A（単線・機関室外）に従い、絶縁体の耐熱温度 60 / 75 / 90 / 105℃ と、束ねる本数（1本、2〜3本、4〜6本、7〜24本、25本以上）で低減します。
  • 許容する電圧降下は、重要な回路（分電盤、電子機器、航海灯）の 3% と、それ以外の 10% をプリセットで用意。0.5% 刻みで任意の値にもできます。

逆算

手持ちの電線から考えることもできます。AWG を選んで電流を入れれば引ける最大の片道長が（メートル換算つきで）、配線長を入れれば流せる最大の電流が出ます。その電線ではそもそも電流を流せない場合は警告します。

AWG 早見表

18 から 4/0 までについて、断面積 mm²（スケア／sq）、耐熱温度別の許容電流、1000ft あたりの抵抗を一覧にしています。AWG と mm² の対応を確認したいときにも使えます。

現場で使う道具として

  • 屋外やガレージ、船の上でも読める、大きく高コントラストな表示。
  • 結果はワンタップでコピーして、メモやメッセージに貼れます。
  • 入力した値は次に開いたときも残ります。
  • 完全にオフラインで動きます。アカウント不要、広告なし、サブスクなし、権限要求もゼロ。入力した内容が端末から出ることはありません。

使う前に知っておいてほしいこと

  • 計算の基準は ABYC E-11（米国の小型舟艇の電気規格）です。日本の内線規程や電気設備技術基準への適合判定は行いません。
  • 配線長の入力はフィート（ft）です。逆算の結果にはメートル換算も表示します。
  • 結果は AWG で表示します。mm²（スケア）は早見表で対応を確認してください。
  • ヒューズやブレーカなどの過電流保護のサイズは対象外です。
  • 検討用の目安であり、ABYC 規格そのもの・電気工事の専門家・各地の法規の代わりにはなりません。配線の前に必ず確認してください。
