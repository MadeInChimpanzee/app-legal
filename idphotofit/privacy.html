プライバシーポリシー

アプリ名：証明写真ぴったり　／　最終更新日：2026年7月22日

証明写真ぴったり（以下「本アプリ」）は、利用者のプライバシーを尊重して設計されています。本アプリは、個人情報を収集せず、外部に送信しないことを基本方針としています。本ポリシーは、本アプリの情報の取り扱いについて説明します。

1. 収集する情報

本アプリは、氏名・メールアドレス・電話番号などの個人を特定できる情報を一切収集しません。アカウント登録やログインは不要です。

2. データの保存場所

利用者が入力・記録した内容、設定などの利用データは、すべて利用者の端末内にのみ保存されます。これらのデータが開発者や第三者のサーバーに送信・保存されることはありません。アプリを削除すると、これらのデータも端末から削除されます。

3. 顔データ（フェイスデータ）の取り扱い

本アプリは、証明写真の規格に合わせて写真を自動で切り抜くために、Apple の Vision フレームワーク（VNDetectFaceLandmarksRequest および VNGeneratePersonSegmentationRequest）を用いて、利用者が撮影・選択した写真から顔の位置（顔矩形）・目の高さ・あご先の位置・頭頂の位置といった幾何情報のみを検出します。

  • 利用目的：頭のサイズと位置が規格（パスポート、マイナンバーカード等）の寸法に収まるよう、拡大率と切り抜き位置を自動計算するためだけに使用します。
  • 処理場所：検出はすべて利用者の端末内（オンデバイス）で完結します。写真および検出結果が開発者のサーバーや第三者に送信されることは一切ありません。本アプリはネットワーク通信を行いません。
  • 保存・保持期間：検出した顔の幾何情報はメモリ上でのみ保持され、端末内にも保存されません。画面を閉じる、または別の写真を選ぶと直ちに破棄されます。顔認証テンプレート・生体認証情報・個人を識別するための顔データを作成・保存することはありません。
  • 第三者提供：顔データを第三者に共有・販売・提供することはありません。広告や解析にも使用しません。
  • 成果物の保存：完成した証明写真の画像は、利用者が保存操作を行った場合にのみ、利用者自身の端末の写真ライブラリに保存されます。開発者はこれにアクセスできません。

Face Data (English). This app uses Apple’s on-device Vision framework to detect only facial geometry — the face bounding box, eye line, chin point and top of head — from a photo the user takes or selects. This information is used solely to compute the crop and scale required to fit official ID photo specifications (passport, My Number card, etc.). All detection is performed entirely on the user’s device; neither the photo nor the detected face data is ever transmitted to the developer or to any third party, and the app performs no network communication at all. Face data is held in memory only, is never written to storage, and is discarded as soon as the user leaves the screen or selects another photo. No face template, biometric identifier or face recognition data is created, stored, shared or sold. The only output that is saved is the finished ID photo image, which is written to the user’s own photo library only when the user explicitly taps save; the developer has no access to it.
