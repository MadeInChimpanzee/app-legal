FDA food label maker & PDF

New: an ingredient library. Save an ingredient once, reuse it in every recipe, and update every label when a supplier spec changes.

What it does

HOW IT WORKS

Add each ingredient with its nutrient values per 100 g (from your supplier spec sheet or a nutrient database) and the grams used. Set servings per container and the serving size. LabelForge sums the batch, divides per serving, and applies the FDA rounding rules automatically. Preview the panel live and export a high-resolution PDF or PNG.

INGREDIENT LIBRARY

Save an ingredient once — nutrients per 100 g and allergens — and pick it in any recipe. Already have recipes? Add all their ingredients to the library in one tap. Supplier changed a spec? Edit the library ingredient and LabelForge offers to update every recipe that uses it. Recipes never change silently. Duplicate a recipe to make a new flavor or size in seconds.

INGREDIENT LIST AND ALLERGENS

Ingredients are listed in descending order by weight, ready for the label. Tag the nine US major allergens on each ingredient (milk, eggs, fish, crustacean shellfish, tree nuts, peanuts, wheat, soybeans, sesame) and LabelForge writes the CONTAINS statement, species included.

FINAL BATCH WEIGHT

Baking and drying remove water, not nutrients. Enter the weight of the finished batch and the serving-size grams reflect it while nutrient totals stay the same.

PRINT SHEET

Tile the label at real size (2.5 or 3 inches wide) on Letter or A4 with light cut lines. Print on label stock or plain paper.

DETERMINISTIC AND COMPLIANT

Rounding follows 21 CFR 101.9(c): calories, fats, cholesterol, sodium, carbohydrates, fibers, sugars, added sugars, protein, and micronutrients. % Daily Values use the 2016 FDA Daily Value table; vitamins and minerals use the 2, 5 and 10 percent increments. Serving size grams and "about" servings per container follow 21 CFR 101.9(b). A built-in reference screen shows the exact rules and values used.
